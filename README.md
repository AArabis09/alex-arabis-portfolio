# Alex Arabis — Portfolio Website

A responsive, dark technical portfolio website built with plain HTML, CSS, and JavaScript. Designed to complement the resume for IT support and web development opportunities.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For local development, you can use the **Live Server** extension in Visual Studio Code.

No build step or package installation is required.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `alex-arabis-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.
